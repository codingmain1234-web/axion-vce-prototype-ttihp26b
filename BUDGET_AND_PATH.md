# Minimum-budget fabrication path

Target route: Tiny Tapeout digital MPW.

At the time this project was prepared (2026-09-16), Tiny Tapeout's public calculator showed
a 70 EUR per-tile example for digital projects. Development boards are a separate cost.

For the minimum-risk first attempt:

1. Start with **1x1 digital tile**.
2. Run all GitHub checks before ordering.
3. Do not increase tile count unless the design fails area checks.
4. A development kit is useful for testing the real chip, but it is not part of the silicon logic itself.

The direct IHP MPW price per square millimetre is far higher than a Tiny Tapeout tile,
so direct foundry area purchase is not the minimum-budget path for this first prototype.

Current price and shuttle availability can change; re-check before payment.
